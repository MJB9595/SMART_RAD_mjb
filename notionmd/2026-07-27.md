# [팀 요약] 2026년 7월 27일 작업 기록

## 🧑‍💻 담당자: 김재아 (MJB9595)

### 1. 프론트엔드-백엔드 보안 권한 충돌(403 버그) 정교화
- **문제점**: 백엔드의 엄격한 IDOR 방어 패치 탓에 일반 직원이 본인 프로필 조회 시에도 403 Forbidden 에러가 발생.
- **해결 방안**: 컨트롤러의 클래스 레벨 인가를 제거하고, 메서드 레벨에서 Spring Expression Language(SpEL)를 활용해 `authentication.principal.employeeId`와 요청 ID를 비교하여 본인에 한해 조회를 허용하도록 리팩토링 (`EmployeeController`, `RecordController`).

### 2. 대시보드 컴포넌트 프론트엔드 최적화
- **내용**: 대시보드의 '부서별 정원 현황' 페이지가 전체 사원 목록 API를 불필요하게 찌르는 현상 수정.
- **해결 방안**: 새롭게 생성된 전용 대시보드 API(`GET /api/dashboard/headcount`)를 직접 연동하여 렌더링 성능 최적화 완료. (`DashboardController` 일반 직원 권한 완화 포함)
