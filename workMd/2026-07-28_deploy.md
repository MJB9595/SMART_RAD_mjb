---

## 1. 배포 환경 및 개요
- **대여서버 (VPS)**:
  - 목적: 외부 테스트 및 리뷰용 운영 환경.
  - 구성: Docker Compose (`docker-compose.vps.yml`), Caddy(리버스 프록시, SSL).
- **개인서버**:
  - 목적: 내부 개발/테스트 및 백업 운영.
  - 구성: 개인 서버 환경에 직접 배포 및 최신화.

## 2. 세부 배포 내역
- **Docker 이미지 빌드 및 전송**:
  - 백엔드/프론트엔드 최신 소스코드를 기반으로 Docker 이미지 빌드 (`kim-backend:latest`, `kim-frontend:latest`).
  - 로컬에서 이미지 저장(`docker save`) 후 대여서버 및 개인서버로 압축본(`hris-images-vps.tar.gz`) 전송.
- **서비스 구동 (Docker Compose)**:
  - 서버 측에서 기존 컨테이너 중지 및 새 이미지 로드 (`docker load`).
  - DB, 백엔드(Spring Boot), 프론트엔드(Next.js) 컨테이너 재가동.
- **Git 최신화 (개인서버)**:
  - 개인서버 로컬 저장소에서 `git pull` 수행하여 최신 코드 반영 후 도커 컴포즈 런.
- **웹 서버 (Caddy)**:
  - Caddyfile을 이용해 80 및 443(HTTPS) 포트 오픈.
  - HTTPS 자동 발급 및 API 요청(/api/*) 리버스 프록시 설정 적용 완료.

## 3. 관련 파일
- `docker-compose.vps.yml`: VPS 배포용 도커 컴포즈 파일.
- `Caddyfile`: 웹 서버 라우팅 및 SSL 발급 설정 파일.
- 배포 스크립트: 자동화 배포용 expect 및 bash 스크립트.

## 4. 특이사항
- 배포 간 무중단 혹은 최소 중단 방식을 위한 컨테이너 핫 리로드(recreate) 절차 준수.
- 개인서버는 직접 git 명령어로도 최신화 및 빌드가 가능하도록 구조화 유지.
