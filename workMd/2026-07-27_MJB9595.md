## 1. 작업 목적

- IDOR 보안 취약점을 방어하여 403 오류를 해결하고, 대시보드에 실데이터를 반영하기 위한 API 연동을 수행합니다.

## 2. 세부 내역 (API 명세, UI 변경점 등)
- **수당/휴가정책 등록 폼 (9d8ca57)**

  - `POST /leave-policies`: 직급, 연차, 이월, 반차, 비고 데이터 등록.
- **근태·경조비·증명서 등록 폼 (addee6e)**

  - `POST /welfare/certificate`: 증명서 신청 폼.
- **대시보드 기능 (99cb7aa)**

- **계정 및 권한 (fb0f607)**

- **근태 처리**: 일일 근태 등록 시 상태를 `ANNUAL_LEAVE`로 매핑합니다.
