# [작업 이력] 전역 텍스트 줄넘김(줄바꿈) UI 버그 수정

> 작업일: 2026-07-22
> 적용 브랜치: 없음
> 적용 커밋: 없음
> 현재 상태: 미완료 (요청 상태)

---

## 1. 작업 목적
전체 프론트엔드 여러 화면에서 좁은 컬럼/셀 안의 텍스트가 글자 단위로 줄바꿈되는 현상을 해결하여 가독성을 높이고 UI를 개선합니다.

## 2. 세부 내역 (API 명세, UI 변경점 등)
- 짧은 고정값 셀(이름, 사번, 날짜, 상태, 구분 등)에 `whitespace-nowrap` 속성 적용.
- 셀 `min-width` 지정 또는 테이블 레이아웃 조정으로 최소 폭 확보.
- 모달 및 카드 컨테이너 폭을 콘텐츠에 맞게 충분히 확보.
- 매우 긴 텍스트(메모/설명 등)에 대해서만 예외적으로 `break-words` 허용.

## 3. 처리 기준 / 비즈니스 로직
- CJK(한글) 텍스트의 임의 줄바꿈과 날짜/숫자의 하이픈 줄바꿈 현상을 방지.

## 4. 공통 기능 및 보안 (선택 사항)
해당 없음.

## 5. 주요 변경 파일
| 구분 | 파일 | 역할 |
|---|---|---|
| (예정) | 전역 UI 컴포넌트 및 CSS 파일 | 공통 UI 줄바꿈 속성 개선 |

## 6. 테스트 및 검증
- 로그인(관리자) → 인사기록 관리 → 교직원 정보관리 → 교직원 가입 승인 모달 및 각 목록 테이블에서 브라우저 창 폭을 줄였을 때 글자 짤림 및 줄바꿈이 정상적인지 검증 (진행 예정).

## 7. 기타/후속 연동 지점
- **교직원 가입 승인 관련 프론트**(현재 김재아 작업 영역)는 `SignupApprovalModal`에서 이미 로컬 수정 완료 (`w-[880px] max-w-[95vw]` 폭 확대 및 각 셀 `whitespace-nowrap` 적용).
