# [작업 이력] 상단 네비게이션바 UI 개선

> 담당: 부현민 (hyunminboo)
> 작업일: 2026-07-23
> 적용 브랜치: frontend
> 적용 커밋: 178e39a (feat(layout): 상단 네비게이션바 검색창 제거 및 경복대학교 로고 추가)
> 현재 상태: 개발 완료

---

## 1. 작업 목적
요구사항에 맞춘 헤더 디자인 개선 및 소속감을 나타내는 학교 로고 배치를 위해 기존의 불필요한 검색창을 제거하고 경복대학교 로고를 추가합니다.

## 2. 세부 내역 (API 명세, UI 변경점 등)
- **TopNav 레이아웃 개편**: 상단 네비게이션 바(`TopNav.tsx`)에서 텍스트 입력 기반의 검색 상자(search-box)를 완전히 제거했습니다.
- **로고 추가**: 검색 상자가 있던 위치에 경복대학교 로고 이미지(`kbu_logo.png`)를 텍스트("경복대학교")와 함께 배치했습니다. 브랜드 컬러(`#E6007E`)를 적용하여 텍스트를 강조했습니다.

## 3. 처리 기준 / 비즈니스 로직
- 상단 네비게이션에서 검색 기능은 현재 요구사항에 포함되지 않아 관련 마크업(input, svg) 요소들을 삭제 처리했습니다.
- 로고 및 타이포그래피는 flex 컨테이너를 사용하여 수직 중앙 정렬되도록 조정했습니다.

## 4. 공통 기능 및 보안 (선택 사항)
- 해당 없음

## 5. 주요 변경 파일
| 구분 | 파일 | 역할 |
|---|---|---|
| 추가 | `frontend/public/kbu_logo.png` | 상단 네비게이션 바에 표시될 경복대학교 로고 이미지 파일 |
| 수정 | `frontend/src/components/layout/TopNav.tsx` | 검색창 마크업을 제거하고 로고 및 텍스트를 렌더링하도록 UI 컴포넌트 수정 |

## 6. 테스트 및 검증
- 브라우저 상에서 화면 렌더링 시 상단 네비게이션 영역에 로고가 정상적으로 표시되는지 시각적 검증 완료.
- 불필요한 검색 기능이 완전히 제거되어 레이아웃이 깨지지 않는지 확인.

## 7. 기타/후속 연동 지점
- 이후 통합 검색 기능이 다시 필요해질 경우, 별도의 검색 전용 컴포넌트나 모달 레이어로 구현하는 것을 권장합니다.
